# Course Notes

A simple GitHub Pages site with download links for notes and assignments.

## Adding material
1. Put the file in `files/<module>/` (lowercase names, no spaces).
2. Add one entry to `topics.json`.
3. Commit. The site updates in a minute or two.

## Publishing
1. Create a public GitHub repo and upload everything in this folder.
2. Settings > Pages > Deploy from a branch > `main` and `/ (root)`.
3. Your site will be at `https://<username>.github.io/<repo-name>/`.

## Notes
- The sample PDFs in `files/` are placeholders. Replace them with your own.
- Public repo content is visible to everyone. Keep answer keys elsewhere.
- Files must be under 100 MB each.
